# 真人表演与声画物理

本文件把“真人感、真实、电影感”转成可观察、可生成、可审查的动作与声音指令。只选择剧情和景别真正需要的项目，不用随机微动作填满镜头。

## 适用边界

- 人物可见时使用本文件；纯空镜只使用环境、材质、镜头和声音因果规则。
- 默认是无对白、无演唱的故事型MV：嘴唇闭合但放松，不说话、不哼唱、不做音素口型。
- H3不接收原始歌曲或其他音频，不做音频驱动；原曲只在最终剪辑阶段加入。
- 真人感来自因果、重量、时间和回收，不来自“动作很多”“持续微动”“每两秒眨眼”等机械指令。

## 四层表演链

每个主要剧情拍点按需写出以下四层：

1. **注意**：视线有具体目标，眼睛通常先于小幅头部转动，头部再带动肩胸或身体。
2. **情绪**：认知变化先落在眼睑、眉间、面颊、下颌、吞咽或呼吸，不瞬间切成夸张表情。
3. **行动**：手、姿态、重心、步伐、握力或道具操作服务一个清晰目标。
4. **回收**：动作减速、惯性消退、表情部分释放，身体重新站稳或准备下一动作。

每个4–15秒镜头只保留一个主导拍点，最多一个次级反应；在设计允许时优先10–15秒。单镜不要同时堆叠转头、眨眼、微笑、点头、挥手、走路和复杂运镜。

## 表演、调度与摄影一体化

人物先有目标和潜台词，再产生注意、身体预备和行动；摄影机根据人物的空间位置、动作结果和观众需要知道的信息选择景别、机位、保持或移动。镜头不能在人物动作之外另演一遍。

- 人物移动时，镜头可以跟随、让位或保持，选择取决于观众要体验同行、观察还是距离；
- 人物发现或理解时，先让表演拍点真实发生，再由小幅推近、焦点转移或切近景帮助观众靠近；
- 人物停下时，身体先减速和站稳，摄影机随后减速并落到新的构图；
- 人物与道具接触时，景别和机位必须看得见关键接触；切镜放在动作阶段或信息发生变化的位置；
- 近景减小表演幅度，宽景用空间、路径和身体姿态表达，不在远景强写看不见的微表情；
- 一镜能完整呈现人物选择和结果时保持一镜，不为“电影感”增加装饰性切换。

## 逐镜真人表演卡

写H3前，在复制框外为每个有人物的镜头确定：

- 起始姿态：身体朝向、承重脚/坐姿支撑点、双手位置、道具接触、视线目标、嘴部状态；
- 内在拍点：本镜唯一的认知或情绪变化；
- 主要动作：一个可在本镜完整完成的动作；
- 辅助微动作：零至两个，由呼吸、视线、环境或主要动作触发；
- 接触与受力：人物、道具、地面和环境之间谁先施力、谁响应；
- 镜头关系：机位、运动原因、幅度、速度和停止方式；
- 结束状态：视线、重心、手部、道具、表情、移动方向和下一镜承接；
- 关键现场声：只选最能证明触感与空间的声音。

## 眼神、眨眼与微表情

- 视线必须有目标：信件、门口、倒影、远处灯光、脚下积水或画外事件；不写无目的左右扫视。
- 眼睛通常先于头部半拍移动；必要时短暂停留，再回到目标或转入下一动作。
- 眨眼不设固定频率，也不要求每个镜头都出现。可在视线转换、认知变化、动作完成后的注意停顿或事件边界安排一次自然单眨；持续追踪目标、精细接触、跨越障碍或关键信息出现期间优先保持视线，不插入强调眨眼。
- 普通自然单眨的导演审查基线约为0.30—0.40秒：上眼睑较快闭合、完全闭合只极短停留、随后较慢睁开。允许个体与情境差异，但必须表现“闭合快于睁开”的非对称轨迹，不能一两帧闪闭、匀速机械开合或闭合后突然弹开。具体秒数只用于复制框外审查，H3正文不写数字时间。
- 风雨、异物或突发强光才使用保护性快速眨眼；普通安静、回忆、失望或接受场景不使用快速眨眼。情绪性缓慢闭眼、闭眼呼吸或停留属于独立表演动作，应另写闭眼、停留与睁眼过程，不称为自然单眨，也不与同一拍点的自然眨眼重复堆叠。
- 表情使用细部和不对称：轻微眉间收紧、单侧嘴角松动、下颌放松、吞咽、鼻翼轻张、压住的微笑。
- 表情遵循出现—峰值—部分释放；近景幅度更小，远景用姿态和动作传达。
- 禁止持续微笑、长期张嘴、凝固大眼、眉毛装饰性乱动、所有人物同步眨眼。

## 呼吸、重心、步态与恢复

- 呼吸持续但克制，通过胸口、肩部、腹部或衣料的轻微起伏体现；硬质服装或远景降低可见度。
- 起步前先把重心移向支撑脚，再迈步；转身由眼神/头部引导，肩胸、髋部、脚步依次跟随。
- 脚掌与地面保持可靠接触，步幅与身体位移一致，禁止身体平移而双脚滑行。
- 停步、坐下、起身、弯腰、伸手或转身包含加速、减速、惯性和重新平衡，不瞬间复位。
- 行走时协调步频、自然臂摆、呼吸、衣摆和相机距离；狭窄空间、湿滑地面、鞋型和服装会限制动作幅度。

## 手部、道具与物理接触

重要操作使用完整接触链：

`目标确认 → 手臂接近 → 手指按物体形状预备 → 接触 → 握力/压力建立 → 物体受力响应 → 搬运或操作 → 释放/稳定 → 手回到休息位`

- 保持惯用手、手指数、握法、接触点、道具尺寸和所有者连续。
- 纸张先受手指压力再弯折；门把先被握住和下压，门体才移动；杯子先建立稳定握持再离开桌面。
- 手不穿过物体，道具不磁吸、跳帧、复制、漂浮或无原因换手。
- 手势有语义和休息状态。没有对白时，避免解释性挥手或持续摆动。

## 环境到身体的因果

- 风：风向统一影响头发、衣摆、站姿、眯眼、握持和必要的相机修正；反应有延迟和回摆。
- 雨：水滴冲击、湿发黏附、衣料吸水、保护性眨眼、脸部转向、鞋底谨慎落地和镜头水滴相互一致。
- 冷热：冷时姿态收紧、手部紧张、动作幅度缩小；热时呼吸、汗液、衣料贴合和动作节奏合理。
- 室内物理：桌椅限制肘部和下肢；玻璃产生真实反射和焦点层次；门窗、纸张、帘布、积水对动作产生可见响应。
- 环境刺激遵循基线—触发—身体/道具/镜头/声音同步反应—短暂恢复—后果保留，不在下一帧重置。

## 衣发和次级运动

- 头发、衣摆、肩带、围巾和耳饰由身体加速度、风、湿度和材质驱动，略晚于主体动作并自然衰减。
- 湿发更重、更贴肤；厚外套惯性小而回摆慢；轻薄裙摆和纸张响应更快。
- 次级运动不能反向违背风向或永不停止，也不能抢过主要动作。

## 真人镜头逻辑

- 镜头服务人物认知变化或动作信息，不为了“高级感”无原因环绕。
- 写清运镜类型、幅度、速度、起因和停止方式；固定镜头就保持真正稳定。
- 跟拍保留操作者惯性和轻微不规则修正，禁止规则循环抖动；稳定器镜头仍需符合空间障碍和主体速度。
- 对焦由注意目标和距离变化触发，焦点转换需要时间；镜头水滴表现为折射、高光和局部对焦干扰，不是全屏脏雾。
- 相机不穿墙、穿人、穿道具，不做无法解释的急停、瞬移或大幅旋转。

## 现场音效与声画同步

- `overall_soundscape` 只写连续环境声、物理动作声和非语言人物声；不写歌曲、配乐、哼唱或对白。
- 关键动作声遵循“可见原因出现—声音起音—空间反射/衰减”。脚步在落地接触时出现，门响在五金受力或门体碰撞时出现，纸声跟随折叠和摩擦。
- 声音透视必须符合机位和空间：近距离呼吸较清楚，远景人物声更弱；室内有适量反射，街道和雨声具有方向与遮挡。
- 每镜选择二至四个关键触感声即可，不要给每个微动作都配夸张拟音；优先脚步、衣料、纸张、门窗、水、交通、风和呼吸中最能建立空间者。
- 现场声之间保持层级，不掩盖核心动作声；结尾保留自然衰减或被下一环境声接管。

## 纯空镜的真实感

- 即使人物不在画面，也必须有明确的力和响应：雨滴落入积水形成波纹、风推动帘布、列车经过改变反射和空气、灯光受遮挡产生变化。
- 材质、光线、景深和相机移动保持干净克制；真人电影感不等于胶片颗粒、数字噪点、脏雾、随机尘埃、强HDR或过度锐化。

## 导演修复与正向编译

木偶感、脚滑、穿模、道具漂移、无因运镜、表情跳变和声音错位等风险只在复制框外审查。修复时重写动作和镜头的正向因果：

- 用明确注意目标、触发、主要动作和恢复状态替代随机持续微动；
- 用重心转移、脚掌落地、步幅和身体位移替代抽象的“自然走路”；
- 用接近、手指预备、接触、受力、物体响应和释放替代抽象的“拿起”；
- 用统一风向、材质延迟和自然衰减明确衣发反应；
- 用可达摄影路径、动作触发、运动幅度、速度和停止构图明确镜头；
- 用稳定身份、服装、道具数量、手部职责和空间位置保持连续。

最终H3复制提示词只写修复后希望发生的正向电影事件，不附加负面控制、禁词或失败风险列表。

## 真人感审查门

逐镜确认：

- 注意目标明确，眼神、头部和身体转动存在先后；
- 情绪变化有出现、峰值和释放，强度符合景别；
- 呼吸、承重、步态、接触和恢复支持主要动作；
- 手部与道具接触链完整，没有穿模或磁吸；
- 衣发和环境反应方向、材质、延迟与衰减合理；
- 镜头运动有物理原因，幅度和速度不过载；
- 现场声与可见原因、距离和空间一致；
- 本镜只有一个主导拍点，人物不会因“真人感指令”而不停乱动。

## 精简编译

本文件是导演审查库，不要求逐条抄入提示词。每镜只编译一个连续事件：起始支撑与人物目标、注意/潜台词触发、一个主要动作及其空间和物理响应、摄影机因人物或信息而反应、动作与神态共同回收到结束构图。眨眼只在本镜确有视线转换、认知变化、动作后的注意停顿、亮度或环境刺激时写一次；若它是可见表演拍点，H3正文只写自然完整单眨、闭合较快、睁开略慢，不写数字秒数，否则不必强行写。若首帧本身重心、手部或路径错误，返回修改图片提示词。
