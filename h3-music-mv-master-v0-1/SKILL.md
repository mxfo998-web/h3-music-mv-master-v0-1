# 故事型音乐 MV 提示词总控

这是完整 MV 提示词工作流的唯一主入口。以歌曲为母时间轴，调用故事组件和图片提示词组件，再统一编排关键帧提示词、中文 H3 提示词、剪辑关系和最终审查。

## 硬性边界：只写提示词

- 只输出角色、场景、道具、关键帧和 H3 的提示词与参考图清单。
- 不调用 `image_gen`、图片 API、图片 CLI 或其他出图工具。
- 不生成、编辑、下载、复制或删除图片，也不委派 Agent 或子 Agent 出图。
- 不声称图片已经生成、审核或达到目标尺寸；只标注目标尺寸和生成后的人工检查项。
- 用户自行生图后，可根据用户重新提供的图片继续修订提示词；仍不代替用户出图。

## 组件路由

调用 `simple-story-mv-maker` 识别或校验歌词、分析歌曲、设计简单故事，并按真实歌曲结构规划连续镜头时间表。该组件只负责规划。

以**提示词模式**调用 `gpt-image-2-cinematic-frames`，写：

- GPT Image 2干净电影画面规范；
- 白底脸部身份图提示词；
- 白底全身正面、严格侧面、背面三视图提示词；
- 无人场景参考图提示词；
- 按上传顺序标注参考图职责的图生图关键帧提示词；
- 关键帧真人状态、支撑重心、双手占用、道具接触、空间路径和环境物理；
- 生成后的身份、解剖、静态物理与可动性人工检查清单。

图片组件不得调用出图工具。可选专业组件也不能突破“只写提示词”的边界。

调用本机 `h3-prompt-writing` 编写H3提示词：

- 默认使用I2VA；
- 先读取其 `references/base-en.txt`；
- 保留 `<Picture 1>`、`[Shot 1]` 等引用标签；
- 严格使用并按顺序排列 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`；
- 字段名和引用标签遵循H3 Skill，字段内容按用户要求使用中文；
- 最终复制提示词只使用三个核心字段，不增加独立首帧控制行、`[负面控制]`、`negative_prompt`、`negative_constraints`、禁词清单、失败风险尾段或第四字段；
- 本MV流程采用用户指定的**无时间单镜兼容模式**：复制提示词内不写 `At`、0.00秒、绝对时间、本地切点或任何数字时间码；每条H3提示词只对应一个独立镜头，只使用 `[Shot 1]`，切镜发生在两条提示词之间，不在一条无时间提示词内写 `[Shot 2]` 或 `[Shot 3]`；
- 在 `integrated_multimodal_description: [Shot 1]` 开头明确 `<Picture 1>` 是目标视频的精确首帧，并从该图已有身份、构图、支撑、接触和光线状态向前发展；不得把此兼容模式表述为官方含时间I2VA模板；
- 生成风险只在复制框外的导演审查中处理；进入H3正文时，改写为肯定、可观察、连续的身份、动作、接触、空间、镜头和结束状态。
- H3只接收该段关键帧图片，不上传歌曲或其他音频参考；
- `overall_soundscape` 只写与画面同步的环境声、动作声和非语言人物声；
- `non_diegetic_music` 固定写 `N/A`，不得在H3提示词中描述歌曲、配乐或后期母音乐。

当画面中出现可见人物时，选择性继承本机 `minimax-h3-digital-human-director-v0-2` 的真人表演规则：

- 必读其 `SKILL.md`、`references/performance-engine.md`、`references/h3-format.md`；审查或修订时再读 `references/review-and-repair.md`；
- 只吸收与叙事真人镜头有关的注意目标、微表情、自然眨眼、呼吸、重心、接触动作、次级运动、环境因果、镜头物理和声画同步规则；
- 剧情型MV同时读取其 `references/scenario-routing.md` 的戏剧表演规则，把人物目标、情绪拍点、身体动作、场面调度和摄影机反应设计成同一连续事件；
- 不因引用数字人组件而自动切换到音频驱动、对白、演唱、口型、乐器表演或Ref2VA；只有用户明确要求相应模式时才读取并应用其专项参考；
- 本Skill的声音边界优先：H3不接收歌曲或其他音频，只有正常现场音效，`non_diegetic_music: N/A`。

## 默认设定

- 简单但具有电影剧情完成度的 story-led：情节保持可生产，人物选择、潜台词、场面调度和视觉叙事达到真人电影MV标准；
- 默认画幅16:9；关键帧目标尺寸3840×2160。只有用户明确要求时才改为9:16或其他画幅；
- 每个镜头4–15秒，时长由歌曲结构、剧情动作和镜头可执行性决定；在不损害音乐落点和剧情节奏时优先10–15秒；不得产生低于4秒或高于15秒的H3生成单元；
- 图片提示词目标为GPT Image 2；
- 视频提示词目标为H3 I2VA，每个镜头计划使用一张独立首帧；
- H3生成阶段不传入歌曲或其他音频，只生成画面需要的正常现场音效，不生成背景音乐；原始歌曲仅在最终剪辑阶段另行铺入；
- 一名主角，最多一名重要次要角色；
- 一个目标、一个障碍、一个核心道具、一次认知变化、一个结尾动作。

## 工作流

### 0. 输入账本

记录音频、歌词或LRC、用户已有参考图、画幅、段长、目标模型、锁定内容和未知项。区分已提供事实、识别结果、合理假设和高影响缺口。

### 1. 歌曲与简单故事

调用故事组件，取得实测时长、歌词校验、歌曲结构、情绪路径、故事卡和连续镜头时间表。先按真实乐句、歌词转折、音乐事件和剧情需求确定切点，再验证每镜4–15秒并尽量保持10–15秒。用户歌词是锁定文本；没有证据时不得伪造歌词、BPM、和弦、音符或逐字时间。

### 2. 导演总谱与连续性

确定一句话概念、视觉章节、角色关系、核心道具、色彩变化、动机光、镜头逻辑及首尾呼应。读取 `references/global-director-score.md`，在任何逐段关键帧或H3设计之前建立整曲导演总谱：N故事状态、P主观立场、D情绪距离/景别、K运动能量、S空间状态、A表演强度、L光色状态。选择有故事依据的渐近、释放、呼吸递进、对立摆动或稳态断裂主曲线；歌曲能量优先影响K但不能单独决定D，副歌也不预设近景或远景。

按歌曲章节先确定七条曲线，再拆到4–15秒的独立镜头。为每镜写主导景别、透视倾向、机位高度、视线关系、镜头新增的信息和切镜依据。D1大远景、D6近景、D7大特写默认作为有限强调资源且不设通用固定比例；若某类作品让其中一种成为常态，改用空间、光色、动能、静止或主观立场承担高潮。重复副歌必须在故事、主观、景别振幅、空间、表演或光色上真实发展。每镜先写角色的可见目标、阻力、潜台词、决定性动作和结束变化，再由人物在空间中的调度决定景别、机位、运镜和镜头边界。

建立角色、服装、场景、道具和叙事状态账本。相邻镜头不要求后一镜精确继承前一镜尾帧、姿势、承重脚、手部位置或运动惯性，也不把上一镜尾帧作为默认参考图；每个镜头独立设计可成立、可起动的首帧。仍需保持人物身份、既定服装、道具归属、故事事实、时间天气和空间关系，或明确说明有意的时空跳转。每次切镜必须由新信息、空间变化、动作阶段、主观转折或音乐结构支持。

### 3. 角色与场景提示词

按顺序写：主角白底脸部、主角白底全身三视图、需要的次要角色、场景参考图、必要道具图。每个资产必须标注资产ID、用途、目标尺寸、画幅、输入图片顺序和完整中文提示词；无输入时写“无；根据文字新生成”。

### 4. 逐段关键帧提示词

每个镜头写：

1. 绝对时间和时长；
2. 计划上传的图生图输入，严格按上传顺序列出；
3. 每张输入图的唯一职责；
4. 目标尺寸和完整中文 GPT Image 2 提示词；
5. 提示词内写清当前冻结时刻的注意目标、自然眼睑、低幅微表情、承重/支撑、左右手占用、接触受力、可行移动路径和下一动作方向；
6. 生成后的人工检查项：身份、三视图、场景、服装、道具、光线、解剖、真人状态、静态物理、下一动作可动性和画面清洁度。

不得写“同上一镜”。每条关键帧提示词必须可独立复制且只描述一个冻结时刻。优先选择动作开始前、接触刚建立或动作结果已经稳定的瞬间；不把人物冻结在半眨眼、失去支撑、双手冲突、道具悬浮或路径不可行的状态。不得生成关键帧。

### 4.5 图片到视频物理门

写H3前先回答两问：

1. **这一帧站得住吗？** 重心、支撑、左右手、道具、光源、反射、风雨和移动路径在静态画面中成立。
2. **这一帧动得起来吗？** 首帧已经给出下一动作需要的可见接触、活动空间和运动方向，镜头能看见关键动作。

任一答案为否，先修改场景或关键帧提示词；禁止只在H3中用负面词补救错误首帧。

### 5. 中文 H3

每个镜头先在复制框外放置“视频生成说明”，再按本机 `h3-prompt-writing` 的三个核心字段写最终提示词，并应用本流程的无时间单镜兼容模式。默认计划上传用户按方案生成并确认的本镜头首帧作为图片1；在 `integrated_multimodal_description` 开头明确它是目标视频的精确首帧，但不写0.00秒或其他时间码。

“视频生成说明”必须紧邻并位于H3复制框之前，至少包含：镜头ID、歌曲绝对时间范围、H3生成时长、16:9画幅、I2VA无时间单镜兼容模式、计划上传图片及顺序、每张图的唯一职责、本镜头剧情任务、与前后镜头的切镜关系，以及H3不上传歌曲、只生成正常现场声的说明。说明不得被复制按钮复制。

最终可复制H3提示词只包含：

1. `integrated_multimodal_description`；
2. `overall_soundscape`；
3. `non_diegetic_music`。

输入图清单、用途、时长说明、分镜说明和审查项必须显示在复制框外。字段内容使用中文，但H3规定的字段名和图片/镜头标签保持原格式。

复制提示词内禁止出现 `At 00:...`、`0.00秒`、`00:SS.SSS` 或其他时间码。镜头绝对时间、4–15秒生成时长和后期音乐切点只显示在复制框外。每条提示词固定只有一个连续 `[Shot 1]`；需要切镜时结束当前生成单元，并为下一镜另写“视频生成说明”、关键帧和独立H3提示词。

H3输入只列该段首帧图片，不列歌曲或音频。`overall_soundscape` 只描述与画面同步的现场音效；`non_diegetic_music` 必须精确写为 `N/A`。原始歌曲对应区间属于剪辑说明，不能写进H3复制提示词。

每个4–15秒生成单元就是一个镜头，优先设计为10–15秒的连续可用镜头。镜头边界由歌曲结构、人物行动和新增信息决定；相邻镜头可以硬切、匹配切、视线切、动作阶段切、空间切或有意跳切，但不要求后一镜从前一镜精确尾帧继续。无对白和演唱时人物保持安静，嘴唇自然闭合。

每个有人物的场景必须先建立“电影场景导演卡”，再把它编译进 `integrated_multimodal_description`：

1. 本镜头N/P/D/K/S/A/L及其相对前镜的变化，场景目标、阻力和人物未说出口的潜台词；
2. 起始构图、人物在空间中的位置、支撑、手部、道具和注意目标；
3. 一个主导内在拍点，以及由它触发的主要动作和最多一个次级反应；
4. 人物从预备、行动、接触、受力、结果到恢复的连续表演与调度路径；
5. 进入、主导、退出和强调景别，透视倾向、机位高度和视线关系；摄影机为何处在这个位置、为何保持静止或开始移动，以及移动如何与人物动作共同起止；
6. 本镜头为何从前镜切入、为何在此结束，以及切换新增的故事、空间、动作或主观信息；
7. 动作完成后的明确结束画面，以及环境、光线、道具和现场声留下的后果；结束画面不作为下一镜必须精确继承的尾帧。

不要把所有“真人感”动作平均塞进每镜。眨眼必须由视线转移、认知变化、动作完成、注意停顿、风雨或亮度刺激等情境触发，不写固定频率，也不在每个镜头机械安排；持续追踪目标、精细接触或高注意动作期间可以不明确安排眨眼。普通自然单眨若作为可见表演拍点，导演审查可参考约0.30—0.40秒的完整眼睑轨迹，但该数值不复制进无时间H3正文；正文只写自然完整单眨、闭合较快、睁开略慢。情绪性闭眼或闭眼呼吸是独立动作，不能冒充自然眨眼。表情遵循出现—峰值—部分释放；走动先转移重心再迈步，停止时保留惯性和站稳；拿取道具遵循接近—手指预备—接触—受力/抓握—物体响应—释放/稳定。无对白、无演唱时嘴唇闭合但放松，不出现说话或哼唱口型。

最终H3正文按一个连续电影事件编译：`<Picture 1>精确首帧关系与起始构图 → 场景目标和注意/潜台词触发 → 人物动作与空间调度 → 摄影机因人物和信息而反应 → 动作、神态、光线、声音共同落到结束画面`。一条提示词内部不切镜，只使用 `[Shot 1]`。动作、神态和镜头不能拆成互不关联的清单；每镜最多一个主导拍点和一个次级反应。具体接触声、脚步声、纸张声、呼吸、叹气或其他同步非语言人物声必须写在发生它的镜头事件中，`overall_soundscape`再用一个连续段落概括本镜现场声。最终复制提示词不得保留 `SS.SSS`、花括号占位、编写说明、时间码、负面控制或失败风险尾段。

### 6. 总审查与交付

检查歌词、镜头时间表、每镜4–15秒且优先10–15秒、故事、切镜逻辑、全局N/P/D/K/S/A/L导演总谱、景别主曲线与极端景别预算、图片提示词结构、参考图顺序、关键帧静态物理与可动性、H3三个字段顺序与中文内容、无时间单镜兼容模式、视频生成说明、电影场景导演卡、真人表演、场面调度、镜头动机、动作物理、声画因果、原歌曲声音归属、复制边界和主题化HTML，以及HTML首屏、目录内层、正文、页脚是否复用同一内容容器并在桌面与移动视口保持对齐，全程是否未调用出图工具或声称已出图。先审图片是否“站得住、动得起来”，再在复制框外修复全片景别无发展、歌曲能量被误写成持续近景/快切/运镜、重复副歌视觉复刻、高潮资源提前透支、木偶僵硬、周期眨眼、空洞凝视、表情跳变、脚滑、无重心转移、手穿物、磁吸道具、力与路径错误、无动机运镜、无信息切镜、轴线混乱、衣发反应错误、循环抖动或声音错位；H3正文只保留修复后的正向电影事件。复制按钮只能复制最终模型提示词，不能复制资产ID、目标尺寸、用途、参考图清单、视频生成说明、分镜说明或审查项。用户要求修改时，返回完整更新版。

## 停止条件

- 歌词无法可靠取得且会改变故事时，请求歌词或校正文本。
- 用户已有参考图缺失且无法用文字可靠替代时，列为待补输入，不虚构图片内容。
- 当前 H3 界面限制与既定段长或图片数量不符时，重新计算生成单元。
- 任一计划镜头短于4秒或长于15秒时，先移动切点或重新分配相邻镜头时长；不得输出超出范围的H3提示词。
